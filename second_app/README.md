# second_app

A simple quiz app that demonstrates intermediate Flutter concepts. Users start the quiz, answer questions, and view their results with an option to restart.

## Topics Covered

- Adding icons to buttons
- Transparency through alpha colors
- `initState()` lifecycle method
- Ternary expressions (`condition ? true : false`)
- `if` statements in Dart
- `if` statements in lists (conditional list items)
- Data models and class structures
- Creating reusable styled buttons
- Working with lists
- Mutating values in memory
- Managing question index as state
- Using 3rd party packages (Google Fonts)
- Passing data across widgets
- Type casting
- `Expanded` widget for flexible layouts
- Scrollable content (`SingleChildScrollView`, `ListView`)
- Screen navigation and state switching
- Map and list operations
- Building result summaries
